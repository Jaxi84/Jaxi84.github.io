IoT Nightlight

An ESP8266-based nightlight controlled through a Telegram bot, with timers, sensor readings and a practical physical installation.

Project from 2021ESP8266 hardwareStill in practical use

The project

Small device.
Real interaction.

The device connects to Wi-Fi and communicates with Telegram over HTTPS. Through an inline keyboard, the user can control the light without needing a separate mobile application.

Commands include turning the light on or off, timed operation for 10, 20 or 30 minutes, temperature readings and an LDR-based light check.

ESP8266Arduino / C++Telegram Bot APIWiFiClientSecureArduinoJson

How it works

Hardware, network
and feedback.

01

Connect

The ESP8266 joins Wi-Fi and establishes secure communication with the Telegram API using WiFiClientSecure.

02

Receive

Telegram long polling receives commands and callback queries from the inline keyboard.

03

Measure

Temperature and light sensors share the ESP8266 analog input and are enabled separately for measurement.

04

Act

The main loop controls the light output and turns it off when the selected timer expires.

My contribution

Where software
meets a room.

I built the hardware-oriented solution as part of my ICT studies and connected the physical light to a chat-based control interface.

The project was built early in my programming studies and before AI-assisted development became part of my workflow. The physical nightlight has remained in use, which gives the project an unusually concrete outcome for an early study project.

The archived implementation is not production-ready: credentials, user access control, reconnection handling and sensor calibration would need a modern security and reliability review.
