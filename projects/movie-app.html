The project

Find a film.
Share the conversation.

Our team built a web application for discovering movies and TV shows, saving favourites, writing reviews and sharing media through groups.

The application uses TMDB for movie and TV data. Registered users can manage favourites and reviews, create groups, request membership and share media with other group members. Group owners can manage membership requests and members.

This was an assessed university project completed by a four-person team. The application demonstrates our course work; it is not presented as a production service.

Course context

Advanced Web
Applications Project.

The project was completed as part of a 15-credit Oulu University of Applied Sciences course. I received grade 5.

Over eight weeks, the team used Scrum to plan and deliver the application in short iterations. My role combined Scrum Master responsibilities for the whole project with selected development work.

Movie App is a separate course project from my ATM Group Project. The projects had different teams, goals and technical work.

The application

Frontend to data.
One shared product.

The team connected a responsive interface, application logic and persistent data around shared movie and TV experiences.

01

Frontend

React and Vite power the browser interface for searching, viewing details and using account and group features.

02

Backend

A Node.js HTTP backend provides application routes and services for the frontend.

03

Data and identity

PostgreSQL stores users, favourites, reviews, groups, memberships and shared media. The application uses JWT access and refresh tokens for authentication.

04

Integration and delivery

TMDB supplies movie and TV information. Docker Compose supports the development environment and GitHub Actions runs the project CI workflow.

My contribution

Team facilitation
and development.

I was the Scrum Master for the full project and helped the team keep its work, decisions and progress visible.

  • Facilitated Scrum events from Sprint 0 through Sprint 6 and maintained the team's working practices and project documentation.
  • Created and configured the team's Jira and Confluence spaces, then maintained their settings and access. I arranged an extension to Atlassian's default 30-day trial.
  • Set up Jira work logging and reporting, and connected Jira with GitHub.
  • Documented ways of working, the Definition of Done, meeting notes and retrospectives in Confluence.
  • Implemented the user account deletion endpoint, removing related user data in a database transaction, and wrote Jest tests for the deletion logic and Supertest-based tests for the authenticated REST endpoint.
  • Built the first version of the movie and TV search feature.
  • Contributed to group features, including early frontend work on the Groups page.
  • Created the starting template for the team's project presentation website.

The group features were developed by the team. My contribution to the Groups page was an initial foundation, not ownership of the complete feature.
