Info-TV

An information display system used in a workplace, connecting scheduled media updates, a browser carousel and an automatically rendered lunch menu.

Final project, 2022Workplace use during internshipIntegration project

The project

A screen that
keeps itself current.

Info-TV combines a local web display with automated content handling. Images are downloaded from Google Drive, displayed in a Bootstrap carousel and refreshed regularly in the browser.

A PHP script parses a restaurant's online lunch menu, renders it as an image and uploads it to Google Drive. A Python downloader then makes that content available to the display.

PythonPHPHTML / JavaScriptGoogle Drive APIBootstrap

System flow

Content in motion.

01

Collect

The Python downloader authenticates with Google Drive and retrieves image content into a temporary directory.

02

Prepare

The PHP menu tool extracts restaurant data and renders it as a PNG for consistent display.

03

Display

PHP scans the media directory and presents images through a Bootstrap carousel with the current ISO week.

04

Refresh

The browser reloads periodically so the screen can keep showing updated material without manual intervention.
